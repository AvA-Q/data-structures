# 第 6 章 图

## 6.1 图的基本概念

图由顶点集合和边集合组成。

```text
G = (V, E)
```

- `V`：顶点集合。
- `E`：边集合。

### 有向图和无向图

- 无向图：边没有方向。
- 有向图：边有方向，也叫弧。

有向边：

```text
<u, v>
```

表示从 `u` 指向 `v`。

无向边：

```text
(u, v)
```

表示 `u` 和 `v` 之间相连。

### 完全图

无向完全图：

> 任意两个顶点之间都有一条边。

边数：

```text
n(n - 1) / 2
```

有向完全图：

> 任意两个顶点之间都有方向相反的两条弧。

弧数：

```text
n(n - 1)
```

### 度

无向图：

- 顶点的度：与该顶点相连的边数。
- 所有顶点度之和等于边数的 `2` 倍。

有向图：

- 入度：指向该顶点的弧数量。
- 出度：从该顶点发出的弧数量。
- 度 = 入度 + 出度。
- 所有顶点入度之和等于弧数。
- 所有顶点出度之和等于弧数。

### 路径、回路、连通性

- 路径：顶点和边交替组成的序列。
- 回路：起点和终点相同的路径。
- 简单路径：顶点不重复。
- 简单回路：除起点和终点外，顶点不重复。

无向图：

- 连通：两个顶点之间有路径。
- 连通图：任意两个顶点之间都连通。
- 连通分量：无向图中的极大连通子图。

有向图：

- 强连通：两个顶点可以互相到达。
- 强连通图：任意两个顶点互相可达。
- 强连通分量：有向图中的极大强连通子图。

### 生成树

生成树是连通无向图的一棵子图。

条件：

- 包含图中全部顶点。
- 正好有 `n - 1` 条边。
- 连通且无回路。

## 6.2 图的存储结构

### 邻接矩阵

使用二维数组保存顶点之间的关系。

无向图：

```text
A[i][j] = 1  表示 i 和 j 相邻
A[i][j] = 0  表示不相邻
```

有向图：

```text
A[i][j] = 1  表示存在 i -> j
```

带权图：

```text
A[i][j] = 权值
```

优点：

- 判断两点是否相邻方便。
- 适合稠密图。
- 容易求顶点度数。

缺点：

- 空间复杂度 `O(n^2)`。
- 稀疏图浪费空间。

### 邻接表

每个顶点维护一个邻接点链表。

优点：

- 存储稀疏图更节省空间。
- 遍历某顶点的所有邻接点方便。

缺点：

- 判断两个点是否相邻可能需遍历链表。
- 无向图每条边通常存两份。

有向图：

- 邻接表表示出边。
- 逆邻接表表示入边。

### 十字链表

用于有向图。

每个弧结点保存：

- 弧尾。
- 弧头。
- 指向同弧尾下一条弧的指针。
- 指向同弧头下一条弧的指针。

优点：

- 容易找入边。
- 也容易找出边。

### 邻接多重表

用于无向图。

每条边只存一份。

适合频繁删除边或修改边的场景。

## 6.3 图的遍历

### 广度优先遍历

简称 BFS。

思想：

1. 从起点出发，访问起点。
2. 依次访问起点的所有邻接点。
3. 再访问这些邻接点的邻接点。
4. 逐层向外扩展。

需要：

- 队列。
- 访问标记数组。

时间复杂度：

- 邻接矩阵：`O(n^2)`。
- 邻接表：`O(n + e)`。

应用：

- 无权图单源最短路径。
- 求连通分量。

### 深度优先遍历

简称 DFS。

思想：

1. 访问起点。
2. 选择一个未访问邻接点继续深入。
3. 无法继续时回溯。
4. 寻找下一个未访问分支。

实现：

- 递归。
- 栈。
- 访问标记数组。

时间复杂度：

- 邻接矩阵：`O(n^2)`。
- 邻接表：`O(n + e)`。

遍历序列可能不唯一。

## 6.4 最小生成树

最小生成树：

> 连通无向图的生成树中，边权之和最小的一棵。

### Prim 算法

从一个顶点开始。

每一步：

1. 找到连接“已选顶点集合”和“未选顶点集合”的最小权边。
2. 把该边和对应顶点加入生成树。
3. 重复 `n - 1` 次。

特点：

- 适合稠密图。
- 朴素实现时间复杂度 `O(n^2)`。

### Kruskal 算法

按边权从小到大选边。

每一步：

1. 选择当前权值最小的边。
2. 如果这条边不形成回路，就加入生成树。
3. 如果形成回路，就舍弃。
4. 重复直到选够 `n - 1` 条边。

特点：

- 适合稀疏图。
- 常用并查集判断是否成环。
- 时间复杂度主要来自排序，约为 `O(e log e)`。

最小生成树可能不唯一。

如果所有边权都不相同，则最小生成树唯一。

## 6.5 最短路径

### BFS 求最短路径

适用于：

- 无权图。
- 边权全部相同的图。

求单源最短路径。

时间复杂度与 BFS 相同。

### Dijkstra 算法

用于求单源最短路径。

思想：

1. 维护起点到各顶点的当前最短距离。
2. 每次选择尚未确定且距离最小的顶点。
3. 用该顶点更新其他邻接点的距离。
4. 重复直到全部顶点确定。

特点：

- 不能处理负权边。
- 朴素实现时间复杂度 `O(n^2)`。
- 可用优先队列优化。

### Floyd 算法

用于求所有顶点对之间的最短路径。

思想：

> 逐个允许中间顶点，动态更新任意两点之间的最短距离。

递推思想：

```text
D[k][i][j]
= min(
    D[k-1][i][j],
    D[k-1][i][k] + D[k-1][k][j]
)
```

时间复杂度：

```text
O(n^3)
```

空间复杂度：

```text
O(n^2)
```

特点：

- 可以处理负权边。
- 不能处理负权回路。

## 6.6 有向无环图

有向无环图简称 DAG。

特点：

> 不存在有向回路。

应用：

- 表示表达式。
- 表示任务依赖关系。
- 拓扑排序。
- 关键路径。

## 6.7 拓扑排序

拓扑排序：

> 把有向图顶点排成线性序列，使每条有向边 `u -> v` 中，`u` 都出现在 `v` 前面。

### Kahn 算法

1. 找入度为 `0` 的顶点并输出。
2. 删除该顶点及其出边。
3. 更新邻接点入度。
4. 重复直到没有入度为 `0` 的顶点。

如果最终输出顶点数小于总顶点数：

> 图中存在环。

### DFS 方法

深度优先遍历完成时记录顶点，最后逆序得到拓扑序列。

拓扑序列可能不唯一。

## 6.8 关键路径

关键路径用于 AOE 网。

AOE 网：

- 顶点表示事件。
- 边表示活动。
- 边权表示活动持续时间。

相关问题：

- 完成整个工程的最短时间。
- 哪些活动是关键活动。

### 关键量

- `ve(v)`：事件最早发生时间。
- `vl(v)`：事件最迟发生时间。
- `e(a)`：活动最早开始时间。
- `l(a)`：活动最迟开始时间。
- `d(a) = l(a) - e(a)`：活动时间余量。

关键活动：

```text
l(a) - e(a) = 0
```

由关键活动组成的路径叫关键路径。

性质：

- 关键路径可能不止一条。
- 缩短关键活动可能缩短总工期。
- 到一定程度后关键路径可能改变。

## 本章结论

- 图由顶点和边组成。
- 无向完全图边数为 `n(n - 1) / 2`。
- 有向完全图弧数为 `n(n - 1)`。
- 无向图所有顶点度之和等于边数的 `2` 倍。
- 邻接矩阵适合稠密图，邻接表适合稀疏图。
- BFS 使用队列，DFS 使用栈或递归。
- Prim 适合稠密图，Kruskal 适合稀疏图。
- Dijkstra 不能处理负权边。
- Floyd 求所有顶点对最短路径，时间复杂度 `O(n^3)`。
- 拓扑排序可用于判断有向图是否有环。
- 关键活动的时间余量为 `0`。
