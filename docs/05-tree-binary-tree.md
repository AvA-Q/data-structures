# 第 5 章 树与二叉树
## 5.1 树的基本概念

树是 `n` 个结点的有限集合。

- `n = 0` 时为空树。
- `n > 0` 时有唯一根结点。
- 其余结点可以分成若干互不相交的子树。

树是一种递归结构：

> 树由根和若干子树组成，每棵子树又是一棵树。

### 常用术语

- 结点的度：结点拥有的子树数量。
- 树的度：树中所有结点度的最大值。
- 叶子结点：度为 `0` 的结点。
- 分支结点：度不为 `0` 的结点。
- 孩子：某结点的直接下层结点。
- 双亲：某结点的直接上层结点。
- 兄弟：同一个双亲的结点。
- 结点的层次：根为第 `1` 层，向下递增。
- 树的高度或深度：树中结点的最大层次。
- 有序树：结点的子树有左右次序。
- 无序树：结点的子树没有次序。
- 森林：若干棵互不相交的树。

### 树的性质

含 `n` 个结点的树有：

```text
n - 1 条边
```

树中所有结点的度数之和等于边数：

```text
所有结点的度之和 = n - 1
```

度为 `m` 的树中，第 `i` 层最多有：

```text
m^(i - 1)
```

个结点。

高度为 `h` 的 `m` 叉树最多有：

```text
(m^h - 1) / (m - 1)
```

个结点。

## 5.2 二叉树

二叉树是每个结点最多有两棵子树的树，并且左右子树有次序。

### 特殊二叉树

#### 满二叉树

每一层都达到最大结点数。

高度为 `h` 的满二叉树结点数：

```text
2^h - 1
```

#### 完全二叉树

按层序编号后，结点与同高度满二叉树的前 `n` 个结点一一对应。

特点：

- 只有最后一层可能不满。
- 最后一层的结点集中在左边。
- 如果某个结点没有左孩子，则一定没有右孩子。

#### 二叉排序树

性质：

- 左子树所有结点关键字小于根。
- 右子树所有结点关键字大于根。
- 左右子树也分别是二叉排序树。

#### 平衡二叉树

任意结点左右子树高度差的绝对值不超过 `1`。

### 二叉树的重要性质

非空二叉树中：

```text
n0 = n2 + 1
```

其中：

- `n0` 是叶子结点数。
- `n2` 是度为 `2` 的结点数。

二叉树第 `i` 层最多有：

```text
2^(i - 1)
```

个结点。

高度为 `h` 的二叉树最多有：

```text
2^h - 1
```

个结点。

含 `n` 个结点的完全二叉树高度：

```text
floor(log2(n)) + 1
```

若完全二叉树从 `1` 开始编号：

```text
结点 i 的左孩子：2i
结点 i 的右孩子：2i + 1
结点 i 的双亲：floor(i / 2)
```

### 二叉树的存储结构

#### 顺序存储

用数组保存结点。

适合：

- 完全二叉树。
- 需要利用父子结点的下标关系。

普通二叉树使用顺序存储可能浪费大量空间。

#### 链式存储

```cpp
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild;
    struct BiTNode *rchild;
} BiTNode, *BiTree;
```

**Python 示例：**

```python
from dataclasses import dataclass

@dataclass
class BiTNode:
    data: object = None
    lchild: "BiTNode | None" = None
    rchild: "BiTNode | None" = None
```

每个结点保存：

- 数据。
- 左孩子指针。
- 右孩子指针。

## 5.3 二叉树的遍历

### 先序遍历

顺序：

```text
根、左、右
```

### 中序遍历

顺序：

```text
左、根、右
```

### 后序遍历

顺序：

```text
左、右、根
```

### 层次遍历

逐层从左到右访问。

层次遍历需要队列辅助：

1. 根结点入队。
2. 访问队头结点。
3. 左右孩子依次入队。
4. 队头出队。
5. 重复直到队列为空。

### 遍历的时间和空间复杂度

时间：

```text
O(n)
```

递归空间最坏：

```text
O(n)
```

### 由遍历序列构造二叉树

可以唯一确定：

- 先序 + 中序。
- 后序 + 中序。
- 层次 + 中序。

一般不能唯一确定：

- 先序 + 后序。

原因：

> 先序或后序可以确定根，中序可以划分左右子树。

## 5.4 线索二叉树

普通二叉树中存在大量空指针。

线索化利用空指针保存遍历前驱和后继。

约定：

- 左孩子为空时，左指针指向遍历前驱。
- 右孩子为空时，右指针指向遍历后继。
- 增加 `ltag`、`rtag` 区分指针和孩子。

`tag` 的含义：

```text
tag == 0  表示指针指向孩子
tag == 1  表示指针是线索
```

常见线索二叉树：

- 先序线索二叉树。
- 中序线索二叉树。
- 后序线索二叉树。

线索化以后，可以不使用栈完成遍历。

找前驱和后继时，要同时检查：

- 当前遍历次序。
- 左右标志。
- 指针实际指向。

## 5.5 树的存储结构

### 双亲表示法

用数组保存每个结点和它的双亲下标。

适合：

- 经常查找双亲。
- 不强调查找孩子。

### 孩子表示法

每个结点保存一个孩子链表。

适合：

- 经常查找孩子。
- 查找双亲不方便。

### 孩子兄弟表示法

也叫二叉树表示法。

每个结点保存：

- 指向第一个孩子的指针。
- 指向下一个兄弟的指针。

```cpp
typedef struct CSNode {
    ElemType data;
    struct CSNode *firstchild;
    struct CSNode *nextsibling;
} CSNode, *CSTree;
```

**Python 示例：**

```python
from dataclasses import dataclass

@dataclass
class CSNode:
    data: object = None
    firstchild: "CSNode | None" = None
    nextsibling: "CSNode | None" = None
```

特点：

- 左指针表示第一个孩子。
- 右指针表示下一个兄弟。

## 5.6 树、森林和二叉树的转换

### 树转二叉树

规则：

1. 每个结点的第一个孩子作为左孩子。
2. 每个结点的右兄弟作为右孩子。

### 森林转二叉树

1. 先把每棵树转换成二叉树。
2. 把各棵树的根结点看作兄弟。

### 二叉树转树或森林

按相反规则恢复：

- 左指针表示孩子。
- 右指针表示兄弟。

## 5.7 树和森林的遍历

### 树的遍历

- 先根遍历。
- 后根遍历。

对应关系：

```text
树的先根遍历 = 对应二叉树的先序遍历
树的后根遍历 = 对应二叉树的中序遍历
```

### 森林的遍历

- 先序遍历森林。
- 中序遍历森林。

森林的先序和中序遍历也可以转换成二叉树的先序和中序遍历。

## 5.8 哈夫曼树

哈夫曼树也叫最优二叉树。

目标：

> 使带权路径长度 `WPL` 最小。

### 路径长度和带权路径长度

- 路径长度：从一个结点到另一个结点经过的边数。
- 结点的带权路径长度：结点权值乘以根到该结点的路径长度。
- 树的带权路径长度：所有叶子结点的带权路径长度之和。

```text
WPL = Σ(wi × li)
```

### 构造方法

1. 把所有带权结点看作只有根的单结点树。
2. 每次选择权值最小的两棵树。
3. 合并成一棵新树。
4. 新根权值等于两者之和。
5. 重复，直到只剩一棵树。

### 哈夫曼编码

应用：

- 数据压缩。
- 前缀编码。

特点：

- 权值大的字符编码短。
- 权值小的字符编码长。
- 任一编码不是另一编码的前缀。
- 哈夫曼树可能不唯一。
- 最小 `WPL` 唯一。

## 5.9 并查集

并查集用于维护若干不相交集合。

支持：

```text
Find(S, x)    查找元素所属集合
Union(S, x, y) 合并两个集合
```

常见实现：

- 使用双亲表示法数组。
- 根结点代表集合。
- `parent[x] == x` 表示 `x` 是根。

### 合并优化

#### 按大小合并

让小集合的根接到大集合的根下。

#### 按秩合并

让较矮的树接到较高的树下。

### 路径压缩

查找时，把查找路径上的结点直接挂到根结点。

效果：

- 降低树高。
- 提升后续查找效率。

同时使用路径压缩和按秩合并后，单次操作近似常数时间。

## 本章结论

- 树是递归定义的一对多层次结构。
- 二叉树左右子树有次序。
- 非空二叉树满足 `n0 = n2 + 1`。
- 完全二叉树适合顺序存储。
- 二叉树遍历包括先序、中序、后序和层次遍历。
- 先序加中序，或后序加中序，可以唯一确定二叉树。
- 线索二叉树利用空指针保存前驱和后继。
- 树和森林可以使用孩子兄弟表示法转为二叉树。
- 哈夫曼树用于构造最优前缀编码。
- 并查集支持合并和查找，优化后效率接近常数级。
