# 第 8 章 排序

> 依据视频原始音轨转写整理，保留原课程的讲解顺序、例子和结论。本文不显示音频时间段。

## 8.1 排序的基本概念

排序：

> 把一组数据按关键字递增或递减重新排列。

分类：

- 内部排序：数据全部在内存中完成。
- 外部排序：数据量大，需要内外存之间交换。

稳定性：

> 如果关键字相同的元素排序后相对次序不变，则排序算法稳定。

稳定性不等于效率高低。

比较排序：

> 通过比较关键字大小决定元素次序。

非比较排序：

- 基数排序。
- 计数排序。

## 8.2 插入排序

### 直接插入排序

思想：

> 把待排序元素插入到前面已经有序的序列中。

过程：

1. 前 `1` 个元素看成有序区。
2. 取下一个元素。
3. 在有序区中从后向前寻找插入位置。
4. 插入元素。

复杂度：

| 情况 | 时间复杂度 |
|---|---:|
| 最好，原本有序 | `O(n)` |
| 最坏，原本逆序 | `O(n^2)` |
| 平均 | `O(n^2)` |

空间：

```text
O(1)
```

稳定。

适合：

- 数据量较小。
- 序列基本有序。

### 希尔排序

思想：

1. 选择一个增量 `d`。
2. 按增量把序列分组。
3. 对每组进行插入排序。
4. 缩小增量。
5. 最终增量为 `1`，进行最后一次插入排序。

特点：

- 也叫缩小增量排序。
- 时间复杂度与增量序列有关。
- 常见近似为 `O(n^1.3)`。
- 空间 `O(1)`。
- 不稳定。

## 8.3 交换排序

### 冒泡排序

思想：

> 相邻元素比较，逆序则交换。

每一趟把最大或最小元素“冒”到最终位置。

复杂度：

| 情况 | 时间复杂度 |
|---|---:|
| 最好，带提前结束标志且原本有序 | `O(n)` |
| 最坏 | `O(n^2)` |
| 平均 | `O(n^2)` |

空间：

```text
O(1)
```

稳定。

### 快速排序

思想：

1. 选择一个枢轴。
2. 把序列划分为小于枢轴和大于枢轴两部分。
3. 对两部分递归排序。

复杂度：

| 情况 | 时间复杂度 |
|---|---:|
| 平均 | `O(n log n)` |
| 最好 | `O(n log n)` |
| 最坏 | `O(n^2)` |

空间：

- 平均递归栈：`O(log n)`。
- 最坏递归栈：`O(n)`。

不稳定。

最坏情况：

> 每次划分极不均匀。

优化：

- 随机选择枢轴。
- 三数取中。
- 小区间改用插入排序。

快速排序的主要时间成本在划分过程。

## 8.4 选择排序

### 简单选择排序

思想：

> 每趟从未排序区选择最小或最大元素，放到已排序区末尾。

复杂度：

```text
O(n^2)
```

空间：

```text
O(1)
```

不稳定。

特点：

- 比较次数固定。
- 元素移动次数较少。

### 堆排序

堆：

> 完全二叉树，并且满足大根堆或小根堆性质。

大根堆：

```text
根结点值 >= 左右孩子值
```

小根堆：

```text
根结点值 <= 左右孩子值
```

升序排序通常使用大根堆。

过程：

1. 建堆。
2. 交换堆顶和末尾元素。
3. 调整剩余元素为堆。
4. 重复。

复杂度：

- 建堆：`O(n)`。
- 每次调整：`O(log n)`。
- 总时间：`O(n log n)`。
- 空间：`O(1)`。
- 不稳定。

堆的插入：

1. 放到末尾。
2. 向上调整。

堆的删除：

1. 通常删除堆顶。
2. 用末尾元素替换堆顶。
3. 向下调整。

## 8.5 归并排序

思想：

1. 把序列不断二分。
2. 将两个有序子序列合并。
3. 递归完成后得到有序序列。

复杂度：

- 时间：`O(n log n)`。
- 空间：`O(n)`。
- 稳定。

特点：

> 时间复杂度稳定，适合外部排序。

## 8.6 基数排序

思想：

> 按关键字的每一位从低位到高位进行稳定分配和收集。

如果关键字有 `d` 位，每一位有 `r` 种取值：

```text
时间：O(d(n + r))
空间：O(r)
```

特点：

- 稳定。
- 不是比较排序。
- 适合位数固定、每位数取值范围较小的关键字。

## 8.7 计数排序

思想：

1. 统计每个值出现的次数。
2. 根据统计结果计算输出位置。
3. 按顺序输出。

复杂度：

- 时间：`O(n + k)`。
- 空间：`O(k)`。

其中 `k` 是值域大小。

特点：

- 稳定，前提是反向填充。
- 适合整数且值域不大的情况。

## 8.8 内部排序比较

| 排序方法 | 平均时间 | 最坏时间 | 最好时间 | 空间 | 稳定 |
|---|---:|---:|---:|---:|---|
| 直接插入 | `O(n^2)` | `O(n^2)` | `O(n)` | `O(1)` | 是 |
| 希尔 | 约 `O(n^1.3)` | 与增量有关 | 与增量有关 | `O(1)` | 否 |
| 冒泡 | `O(n^2)` | `O(n^2)` | `O(n)` | `O(1)` | 是 |
| 快速 | `O(n log n)` | `O(n^2)` | `O(n log n)` | 平均 `O(log n)` | 否 |
| 简单选择 | `O(n^2)` | `O(n^2)` | `O(n^2)` | `O(1)` | 否 |
| 堆排序 | `O(n log n)` | `O(n log n)` | `O(n log n)` | `O(1)` | 否 |
| 归并 | `O(n log n)` | `O(n log n)` | `O(n log n)` | `O(n)` | 是 |
| 基数 | `O(d(n+r))` | `O(d(n+r))` | `O(d(n+r))` | `O(r)` | 是 |
| 计数 | `O(n+k)` | `O(n+k)` | `O(n+k)` | `O(k)` | 是 |

选择建议：

- 基本有序、规模小：插入排序。
- 平均性能优先、内存受限：快速排序或堆排序。
- 要求稳定：归并排序、基数排序、计数排序。
- 值域小且为整数：计数排序。
- 多关键字且位数固定：基数排序。

## 8.9 外部排序

当数据量大于内存时，需要外部排序。

阶段：

1. 生成初始归并段。
2. 对归并段进行多路归并。
3. 形成最终有序文件。

主要优化方向：

- 增加归并路数，减少读写趟数。
- 减少初始归并段数量。
- 优化归并树，减少总 I/O。

### 败者树

败者树用于加速多路归并中的最小值选择。

特点：

- 记录失败者。
- 便于回溯更新。
- 减少反复比较。

### 置换选择排序

用于生成更长的初始归并段。

思想：

1. 内存工作区持续选择可输出元素。
2. 当剩余元素都小于刚输出的元素时，开始新的归并段。
3. 生成的归并段长度可能超过内存工作区大小。

### 最佳归并树

用于确定多路归并方案，使带权路径长度最小。

方法类似哈夫曼树：

- 把每个初始归并段长度看作权值。
- 每次选择最小的若干归并段合并。
- 多路归并时，如果结点数不足以构成严格多叉哈夫曼树，需要补零权结点。

## 本章结论

- 插入排序适合基本有序的数据。
- 希尔排序是不稳定的缩小增量排序。
- 冒泡排序稳定，最好可达到 `O(n)`。
- 快速排序平均 `O(n log n)`，最坏 `O(n^2)`，不稳定。
- 简单选择排序不稳定。
- 堆排序时间稳定为 `O(n log n)`，空间 `O(1)`。
- 归并排序稳定，空间 `O(n)`。
- 基数排序和计数排序不是比较排序。
- 建堆是 `O(n)`，不是 `O(n log n)`。
- 外部排序优化的重点是减少 I/O 次数。
