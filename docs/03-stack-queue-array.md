## 3.1 栈的基本概念

栈是一种特殊的线性表，也是一条操作受限的线性表。

普通线性表可以在任意位置插入和删除，而栈限制：

> 插入和删除只能在栈顶一端进行。

因此栈具有：

```text
后进先出
LIFO
Last In First Out
```

### 使用的例子

1. 石堆  
   新石头只能放到堆顶，也只能从堆顶拿走。

2. 洗好的盘子  
   新盘子摞在顶部，取盘子时也从顶部取。

3. 烤串  
   肉从上方穿入，也从上方开始吃。

这些例子的共同点是：插入和删除都发生在同一端。

### 常用术语

- 空栈：栈中没有数据元素。
- 栈顶：允许插入和删除的一端。
- 栈底：不允许插入和删除的一端。
- 栈顶元素：最上面的元素。
- 栈底元素：最下面的元素。

如果按照 `a1、a2、a3、a4、a5` 的顺序入栈，通常出栈顺序为：

```text
a5、a4、a3、a2、a1
```

### 基本操作

```text
InitStack(&S)       初始化栈
DestroyStack(&S)    销毁栈
Push(&S, x)         入栈
Pop(&S, &x)         出栈，并用 x 返回
GetTop(S, &x)       读取栈顶元素
StackEmpty(S)       判断栈空
```

`GetTop` 和 `Pop` 的区别：

- `GetTop` 只读取栈顶元素，不删除。
- `Pop` 读取栈顶元素并将其删除。

### 合法出栈序列

栈喜欢考察一种题型：

> 给定入栈顺序，判断某个出栈序列是否合法。

基本原则：

- 入栈和出栈可以交替进行。
- 某个元素出栈后，不能从栈底绕过其他元素先出。

如果入栈元素互不相同且总数为 `n`，合法出栈序列数量为卡特兰数：

```text
Catalan(n) = C(2n, n) / (n + 1)
```

例如：

```text
n = 5
Catalan(5) = 42
```

## 3.2 顺序栈

顺序栈使用数组保存数据元素。

典型结构：

```cpp
#define MaxSize 10

typedef struct {
    ElemType data[MaxSize];
    int top;
} SqStack;
```

**Python 示例：**

```python
from dataclasses import dataclass, field

MAX_SIZE = 10

@dataclass
class SqStack:
    data: list = field(default_factory=lambda: [None] * MAX_SIZE)
    top: int = -1
```

栈顶指针可以有两种设计。

### 方案一：top 指向栈顶元素

初始化：

```cpp
S.top = -1;
```

**Python 示例：**

```python
stack.top = -1
```

判断空栈：

```cpp
S.top == -1
```

**Python 示例：**

```python
stack.top == -1
```

入栈：

```cpp
S.data[++S.top] = x;
```

**Python 示例：**

```python
stack.top += 1
stack.data[stack.top] = x
```

出栈：

```cpp
x = S.data[S.top--];
```

**Python 示例：**

```python
x = stack.data[stack.top]
stack.top -= 1
```

判断栈满：

```cpp
S.top == MaxSize - 1
```

**Python 示例：**

```python
stack.top == MAX_SIZE - 1
```

### 方案二：top 指向下一个可插入位置

初始化：

```cpp
S.top = 0;
```

**Python 示例：**

```python
stack.top = 0
```

判断空栈：

```cpp
S.top == 0
```

**Python 示例：**

```python
stack.top == 0
```

入栈：

```cpp
S.data[S.top++] = x;
```

**Python 示例：**

```python
stack.data[stack.top] = x
stack.top += 1
```

出栈：

```cpp
x = S.data[--S.top];
```

**Python 示例：**

```python
stack.top -= 1
x = stack.data[stack.top]
```

判断栈满：

```cpp
S.top == MaxSize
```

**Python 示例：**

```python
stack.top == MAX_SIZE
```

提醒：

> 必须先看清 `top` 指向栈顶元素，还是指向栈顶元素后面的空位。两种约定下代码不同，不能混用。

### 共享栈

两个栈共享同一片数组空间。

- 0 号栈从低地址向高地址增长。
- 1 号栈从高地址向低地址增长。

常见初始化：

```cpp
top0 = -1;
top1 = MaxSize;
```

**Python 示例：**

```python
top0 = -1
top1 = MAX_SIZE
```

栈满条件：

```cpp
top0 + 1 == top1
```

**Python 示例：**

```python
top0 + 1 == top1
```

共享栈可以提高存储空间利用率。

顺序栈的入栈、出栈、读取栈顶和判空操作都可以在常数时间完成：

```text
O(1)
```

## 3.3 链栈

链栈用链式存储实现栈。

链栈本质上是一个只允许在表头插入和删除的单链表：

- 入栈：头插。
- 出栈：删除首结点。
- 栈顶：链表头部。

带头结点和不带头结点都可以实现链栈，课程推荐重点掌握不带头结点版本，但两种都应会写。

链栈的特点：

- 不容易发生传统顺序栈的“栈满”。
- 只要内存足够，就可以继续申请结点。
- 入栈和出栈都是 `O(1)`。

## 3.4 队列的基本概念

队列也是一种操作受限的线性表。

限制：

- 只能从队尾插入。
- 只能从队头删除。

因此队列具有：

```text
先进先出
FIFO
First In First Out
```

使用的例子：

- 食堂排队打饭。
- 汽车在收费站排队。

术语：

- 队头：允许删除的一端。
- 队尾：允许插入的一端。
- 队头元素：最靠近队头的元素。
- 队尾元素：最靠近队尾的元素。
- 空队列：队列中没有数据元素。

基本操作：

```text
InitQueue(&Q)        初始化队列
DestroyQueue(&Q)     销毁队列
EnQueue(&Q, x)       入队
DeQueue(&Q, &x)      出队，并用 x 返回
GetHead(Q, &x)       读取队头元素
QueueEmpty(Q)        判断队空
```

## 3.5 循环队列

顺序队列使用数组保存元素，并设置：

- `front`：队头指针。
- `rear`：队尾指针。

如果每次入队后 `rear` 都一直向后移动，前面出队留下的空间无法重新利用，会产生“假溢出”。

解决方法：

> 对指针移动使用取模运算，使数组在逻辑上变成环形。

### 常见约定一：牺牲一个存储单元

通常让 `rear` 指向队尾元素的下一个位置。

初始化：

```cpp
Q.front = 0;
Q.rear = 0;
```

**Python 示例：**

```python
queue.front = 0
queue.rear = 0
```

队空：

```cpp
Q.front == Q.rear
```

**Python 示例：**

```python
queue.front == queue.rear
```

队满：

```cpp
(Q.rear + 1) % MaxSize == Q.front
```

**Python 示例：**

```python
(queue.rear + 1) % MAX_SIZE == queue.front
```

元素个数：

```cpp
(Q.rear - Q.front + MaxSize) % MaxSize
```

**Python 示例：**

```python
(queue.rear - queue.front + MAX_SIZE) % MAX_SIZE
```

入队：

```cpp
Q.data[Q.rear] = x;
Q.rear = (Q.rear + 1) % MaxSize;
```

**Python 示例：**

```python
queue.data[queue.rear] = x
queue.rear = (queue.rear + 1) % MAX_SIZE
```

出队：

```cpp
x = Q.data[Q.front];
Q.front = (Q.front + 1) % MaxSize;
```

**Python 示例：**

```python
x = queue.data[queue.front]
queue.front = (queue.front + 1) % MAX_SIZE
```

牺牲一个存储单元的原因是：

> 如果不牺牲空间，队空和队满都可能出现 `front == rear`，无法只根据两个指针区分。

### 常见约定二：增加 size

增加变量 `size` 记录当前元素个数。

```text
size == 0        队空
size == MaxSize  队满
```

这样可以利用全部数组空间。

### 常见约定三：增加 tag

增加标记变量 `tag`：

- 最近一次操作是入队：`tag = 1`。
- 最近一次操作是出队：`tag = 0`。

当 `front == rear` 时：

- `tag == 1`：队满。
- `tag == 0`：队空。

### 易错点

题目可能让 `rear` 指向队尾元素，而不是队尾元素的下一个位置。

两种约定下：

- 初始化不同。
- 判空不同。
- 判满不同。
- 入队和出队顺序不同。

必须先看清题目定义。

## 3.6 链队列

链队列用链式存储实现队列。

通常需要两个指针：

- `front`：队头指针。
- `rear`：队尾指针。

### 带头结点

空队列：

```cpp
front == rear
```

**Python 示例：**

```python
front == rear
```

或者：

```cpp
front->next == NULL
```

**Python 示例：**

```python
front.next is None
```

入队：

```cpp
s->next = NULL;
rear->next = s;
rear = s;
```

**Python 示例：**

```python
s.next = None
rear.next = s
rear = s
```

出队：

```cpp
p = front->next;
front->next = p->next;

if (rear == p) {
    rear = front;
}

free(p);
```

**Python 示例：**

```python
p = front.next
front.next = p.next

if rear is p:
    rear = front
```

当删除最后一个结点时，必须修改 `rear`，否则尾指针会悬空。

### 不带头结点

初始时：

```cpp
front = NULL;
rear = NULL;
```

**Python 示例：**

```python
front = None
rear = None
```

插入第一个结点时要同时修改 `front` 和 `rear`。

删除最后一个结点后，也要把 `front` 和 `rear` 都恢复为 `NULL`。

链队列通常不需要判断队满，只要内存足够就可以继续扩展。

## 3.7 双端队列

双端队列允许：

- 两端插入。
- 两端删除。

如果只允许在一端插入和删除，双端队列就退化为栈。

变种：

### 输入受限双端队列

- 只允许一端插入。
- 两端都可以删除。

### 输出受限双端队列

- 两端都可以插入。
- 只允许一端删除。

考试常见形式：

> 判断某个输出序列能否由双端队列产生。

分析原则：

- 栈能产生的合法序列，双端队列一定能产生。
- 先找出栈不能产生的序列，再验证双端队列能否产生。
- 判断较大序号元素输出前，较小序号元素在队列中的相对次序是否已经确定。

## 3.8 栈在括号匹配中的应用

括号匹配用于判断：

- 左右括号数量是否一致。
- 左右括号形状是否对应。

算法：

1. 从左到右扫描字符。
2. 遇到左括号，入栈。
3. 遇到右括号：
   - 如果栈空，匹配失败。
   - 否则弹出栈顶左括号。
   - 检查两者是否为同一种括号。
4. 扫描结束后，栈必须为空。

失败情况：

- 右括号出现时栈为空，说明右括号单身。
- 弹出的左括号与当前右括号不匹配。
- 扫描结束后栈非空，说明左括号单身。

如果用顺序栈实现，应注意栈溢出。实际开发中可以使用链栈。

时间复杂度：

```text
O(n)
```

## 3.9 栈在表达式求值中的应用

### 三种表达式

中缀表达式：

```text
A + B
```

前缀表达式，也叫波兰表达式：

```text
+ A B
```

后缀表达式，也叫逆波兰表达式：

```text
A B +
```

中缀表达式符合人的阅读习惯，但计算机不容易直接判断运算顺序。

前缀和后缀表达式不需要括号，也能无歧义地表示运算顺序。

### 中缀转后缀

手算步骤：

1. 确定中缀表达式中各个运算符的生效顺序。
2. 按生效顺序，把运算符放到对应操作数后面。
3. 每处理完一个运算，就把结果看成一个新的操作数。

为保证计算机算法具有确定性，手算时采用：

> 左优先原则。

含义：

> 只要左边的运算符可以优先计算，就优先选择左边的运算符。

扫描算法：

1. 遇到操作数，直接输出。
2. 遇到左括号，入栈。
3. 遇到运算符：
   - 弹出栈中优先级高于或等于当前运算符的运算符。
   - 然后当前运算符入栈。
4. 遇到右括号：
   - 弹出运算符，直到遇到左括号。
   - 左括号出栈但不输出。
5. 扫描结束后，弹出栈中剩余运算符。

优先级：

```text
乘除 > 加减
```

### 中缀转前缀

手算时采用：

> 右优先原则。

含义：

> 只要右边的运算符可以优先计算，就优先选择右边的运算符。

保证算法确定性时，通常采用右优先原则。

### 后缀表达式求值

算法：

1. 从左到右扫描。
2. 遇到操作数，入栈。
3. 遇到运算符：
   - 弹出两个操作数。
   - 先弹出的是右操作数。
   - 后弹出的是左操作数。
   - 执行运算。
   - 把结果压回栈中。
4. 扫描结束后，栈中只剩一个元素，它就是结果。

注意：

> 减法和除法必须区分左右操作数。

### 前缀表达式求值

与后缀求值方向相反：

1. 从右到左扫描。
2. 遇到操作数，入栈。
3. 遇到运算符，弹出两个操作数。
4. 先弹出的是左操作数。
5. 后弹出的是右操作数。
6. 运算结果压回栈中。

### 中缀表达式求值

可以同时使用两个栈：

- 操作数栈。
- 运算符栈。

实际上是把“中缀转后缀”和“后缀求值”结合起来。

计算机需要把复杂表达式拆解为一条条简单运算。CPU 通常一次只执行一个基本运算，因此表达式求值是编译程序中的重要基础。

## 3.10 栈在递归中的应用

函数调用本身依赖函数调用栈。

每次函数调用时，系统通常要保存：

- 返回地址。
- 实参。
- 局部变量。
- 其他运行信息。

函数调用结束后，从栈顶恢复上一层运行环境。

递归只是函数调用自身，底层仍然使用函数调用栈。

### 阶乘

```text
n! = n × (n - 1)!
```

递归出口：

```text
1! = 1
```

递归深度为 `n` 时，调用栈空间为：

```text
O(n)
```

如果递归层数过大，可能发生栈溢出。

### 斐波那契数列

```text
Fib(n) = Fib(n - 1) + Fib(n - 2)
```

基础情况：

```text
Fib(0) = 0
Fib(1) = 1
```

直接递归会重复计算许多子问题，例如 `Fib(2)`、`Fib(1)` 可能被多次计算。

因此递归实现直观，但不一定高效。

## 3.11 队列的应用

### 树的层次遍历

思想：

1. 根结点入队。
2. 访问队头结点。
3. 把该结点的左右孩子依次入队。
4. 队头结点出队。
5. 重复直到队列为空。

### 图的广度优先搜索

思想：

1. 起点入队。
2. 访问队头顶点。
3. 把所有尚未访问的邻接点入队。
4. 队头顶点出队。
5. 重复直到队列为空。

### 操作系统中的先来先服务

操作系统使用先来先服务策略管理有限资源：

- 进程按到达顺序排队。
- 队头进程先获得 CPU。
- 用完时间片后离开队头。

这与队列的先进先出特性一致。

### 打印机缓冲区

打印机速度通常慢于主机。

当多个打印任务同时到达时，系统把任务按到达顺序放入队列：

1. 先到达的打印任务先处理。
2. 后到达的任务等待。

这样可以在一定程度上缓解主机和慢速设备速度不匹配的问题。

## 3.12 数组和特殊矩阵的压缩存储

### 一维数组

一维数组中的元素类型相同，每个元素占用空间相同，并且在内存中连续存放。

如果下标从 `0` 开始，第 `i` 个元素的地址为：

```text
LOC(ai) = LOC(a0) + i × sizeof(ElemType)
```

如果下标从 `1` 开始：

```text
LOC(ai) = LOC(a1) + (i - 1) × sizeof(ElemType)
```

### 二维数组

二维数组在内存中被拉成一维连续空间。

行优先存储：

> 先存第一行，再存第二行，依次向下。

列优先存储：

> 先存第一列，再存第二列，依次向右。

地址计算时，要先确认：

- 行下标和列下标的起始值。
- 使用行优先还是列优先。
- 每个元素的大小。

### 对称矩阵

对称矩阵满足：

```text
a[i][j] = a[j][i]
```

只需存储：

- 主对角线。
- 下三角区或上三角区。

存储元素数量：

```text
1 + 2 + 3 + ... + n
= n(n + 1) / 2
```

如果按行优先存储下三角，并且数组下标从 `0` 开始，当 `i >= j` 时：

```text
k = i(i - 1) / 2 + j - 1
```

如果 `i < j`，利用对称性转换为：

```text
a[i][j] = a[j][i]
```

然后再代入公式。

### 三角矩阵

下三角矩阵：

- 下三角区非常数。
- 上三角区全部为同一个常数。

上三角矩阵：

- 上三角区非常数。
- 下三角区全部为同一个常数。

非零或非常数区域元素数量：

```text
n(n + 1) / 2
```

还需要额外保存一个常数，因此一维数组长度为：

```text
n(n + 1) / 2 + 1
```

访问常数区时，统一映射到数组最后一个位置。

### 三对角矩阵

三对角矩阵中，满足以下条件的元素可能非零：

```text
|i - j| <= 1
```

除第一行和最后一行外，每一行通常有 3 个待存储元素。

总待存储元素数：

```text
3n - 2
```

如果按行优先存储，并且数组下标从 `0` 开始：

```text
k = 2i + j - 3
```

强调：

> 公式不要死记，要根据每行前的元素数量和当前元素在本行的位置重新推导。

### 稀疏矩阵

稀疏矩阵中非零元素数量远远少于矩阵元素总数。

#### 三元组顺序表

每个非零元素记录：

```text
(行号, 列号, 值)
```

特点：

- 节省空间。
- 失去随机存取。
- 查找元素通常需要顺序扫描。

#### 十字链表

每个非零元素结点保存：

- 行号。
- 列号。
- 值。
- 指向同列下一个非零元素的向下指针。
- 指向同行下一个非零元素的向右指针。

十字链表适合非零元素位置动态变化的稀疏矩阵。

## 3.13 小结

- 栈只能在同一端插入和删除，特点是后进先出。
- 队列只能一端入队、另一端出队，特点是先进先出。
- 顺序栈要区分栈顶指针的两种定义。
- 共享栈可以提高空间利用率。
- 链栈本质是只能在头部操作的单链表。
- 循环队列必须区分队空和队满。
- 链队列必须在删除最后一个结点时正确修改尾指针。
- 双端队列允许两端插入和删除，常用于判断输出序列是否合法。
- 栈可以解决括号匹配、表达式求值和递归问题。
- 队列可以支持树的层次遍历、图的广度优先搜索、任务调度和缓冲区。
- 特殊矩阵压缩存储的关键是根据下标计算一维数组位置。
- 所有位置公式都必须先确认下标从 `0` 还是从 `1` 开始。
