# 第 2 章 线性表
## 2.1 线性表的定义和基本操作

学习线性表时，仍然从数据结构的三个角度分析：

1. 逻辑结构是什么。
2. 需要用哪些基本操作。
3. 不同存储结构下，这些操作如何实现。

### 线性表的定义

线性表是具有相同数据类型的 `n` 个数据元素的有限序列。

可以表示为：

```text
L = (a1, a2, a3, ..., an)
```

定义中要抓住三个关键词。

#### 相同数据类型

线性表中的各个数据元素类型相同。

这意味着：

- 每个数据元素占用的存储空间相同。
- 计算机可以根据起始地址和元素大小快速计算某个元素的地址。

数据元素可以是 `int`、`float` 等基本类型，也可以是自定义的结构类型。

#### 序列

数据元素之间有先后次序。

- 除第一个元素外，每个元素都有唯一前驱。
- 除最后一个元素外，每个元素都有唯一后继。

#### 有限

线性表中的元素数量有限。

> 如果把所有整数按递增顺序排列，虽然元素类型相同，也有先后次序，但元素数量无限，因此不是线性表。

### 常用术语

- 表长：线性表中的元素个数 `n`。
- 空表：`n = 0` 的线性表。
- 位序：元素在线性表中的序号，从 `1` 开始。
- 表头元素：第一个元素 `a1`。
- 表尾元素：最后一个元素 `an`。
- 直接前驱：排在某元素前面的相邻元素。
- 直接后继：排在某元素后面的相邻元素。

特别提醒：

> 位序从 `1` 开始，程序数组下标通常从 `0` 开始。

### 线性表的基本操作

常见操作包括：

```text
InitList(&L)             初始化线性表
DestroyList(&L)          销毁线性表
ListInsert(&L, i, e)     在第 i 个位置插入 e
ListDelete(&L, i, &e)    删除第 i 个元素，并用 e 返回
LocateElem(L, e)         按值查找
GetElem(L, i)            按位查找
Length(L)                求表长
PrintList(L)             输出线性表
Empty(L)                 判断是否为空表
```

所有数据结构的核心操作大体都可以归纳为：

> 创建、销毁、增、删、改、查。

### 为什么使用引用参数

通过 C++ 示例讲解：

```cpp
void test(int x) {
    x = 1024;
}
```

**Python 示例：**

```python
def test(x):
    x = 1024

value = 1
test(value)
print(value)  # 1，整数不可变，函数内不会修改原值
```

如果按值传递，函数内部修改的是实参的副本，返回主函数后原变量不变。

如果使用引用参数：

```cpp
void test(int &x) {
    x = 1024;
}
```

**Python 示例：**

```python
def test(values):
    values[0] = 1024

value = [1]
test(value)
print(value[0])  # 1024，列表是可变对象
```

函数内部操作的就是原变量，修改结果可以带回来。

因此，判断是否使用引用参数的方法很直接：

> 如果函数对参数的修改结果需要带回调用者，就使用引用参数。

线性表的插入、删除和销毁等操作通常需要修改线性表本身，因此线性表参数通常使用引用形式。

### 为什么封装基本操作

把基本操作封装成函数，主要有两个原因：

1. 大型项目通常由团队协作完成，方便其他成员使用。
2. 常用操作只需实现一次，避免反复编写相同代码。

提醒：

> 学习时要经常思考“为什么这样做”，而不只是记“怎么做”。

## 2.2 顺序表

顺序表是用顺序存储方式实现的线性表。

顺序存储的含义是：

> 逻辑上相邻的数据元素，在物理内存中也相邻存放。

### 地址计算

如果第一个数据元素的地址为 `LOC(a1)`，每个元素占 `sizeof(ElemType)` 个字节，则第 `i` 个元素的地址为：

```text
LOC(ai) = LOC(a1) + (i - 1) * sizeof(ElemType)
```

因为每个数据元素大小相同，所以只要知道起始地址，就能直接计算任意元素的地址。

### 静态分配

静态分配使用固定长度数组。

典型结构如下：

```cpp
#define MaxSize 10

typedef struct {
    ElemType data[MaxSize];
    int length;
} SqList;
```

**Python 示例：**

```python
from dataclasses import dataclass, field

MAX_SIZE = 10

@dataclass
class SqList:
    data: list = field(default_factory=lambda: [None] * MAX_SIZE)
    length: int = 0
```

说明：

- `MaxSize` 决定最多能存多少个元素。
- `length` 记录当前实际存了多少个元素。
- 数组容量一旦确定，通常不能改变。

初始化时：

- 可以把数组元素全部置零。
- 必须把 `length` 设置为 `0`。

通过“脏数据”说明：

> 新申请的内存中可能留有以前程序的数据。如果不初始化数组，直接打印超出当前表长的位置，可能看到奇怪数值。

正常访问线性表时不应超过 `length`。

### 动态分配

动态分配使用指针和动态内存申请。

典型结构如下：

```cpp
typedef struct {
    ElemType *data;
    int MaxSize;
    int length;
} SeqList;
```

**Python 示例：**

```python
from dataclasses import dataclass, field

INIT_SIZE = 10

@dataclass
class SeqList:
    data: list = field(default_factory=lambda: [None] * INIT_SIZE)
    max_size: int = INIT_SIZE
    length: int = 0
```
申请空间：

```cpp
L.data = (ElemType *)malloc(
    sizeof(ElemType) * INIT_SIZE
);
```
**Python 示例：**

```python
L.data = [None] * (INIT_SIZE + 0)
```

扩容过程：

1. 申请一块更大的连续空间。
2. 把原空间中的数据复制到新空间。
3. 修改 `data`，使其指向新空间。
4. 修改最大容量。
5. 使用 `free` 释放原空间。


> 动态分配虽然可以扩容，但复制数据的时间开销较大。

课程主要使用 C 语言的 `malloc` 和 `free`。C++ 中可以使用 `new` 和 `delete`。

### 顺序表的特点

1. 随机访问  
   可以在常数时间 `O(1)` 内找到第 `i` 个元素。

2. 存储密度高  
   每个存储单元只保存数据元素本身，不需要额外保存指针。

3. 扩展容量不方便  
   静态分配不能扩展；动态分配扩容时需要复制原数据。

4. 插入和删除不方便  
   为了保持物理连续，通常需要移动大量元素。

## 2.3 顺序表的插入和删除

### 插入操作

在第 `i` 个位置插入元素 `e`。

插入前需要判断：

- `i` 是否合法。
- 顺序表是否已满。

合法插入位置：

```text
1 <= i <= length + 1
```

插入过程：

1. 从最后一个元素开始，依次把元素向后移动一位。
2. 把新元素放入第 `i` 个位置。
3. 表长加 `1`。

核心代码逻辑：

```cpp
for (int j = L.length; j >= i; j--) {
    L.data[j] = L.data[j - 1];
}
L.data[i - 1] = e;
L.length++;
```

**Python 示例：**

```python
for j in range(L.length, i - 1, -1):
    L.data[j] = L.data[j - 1]

L.data[i - 1] = e
L.length += 1
```

注意：

- `i` 是位序，从 `1` 开始。
- 数组下标是 `i - 1`。
- 必须从后往前移动，否则原数据会被覆盖。

时间复杂度：

| 情况 | 移动次数 | 时间复杂度 |
|---|---:|---:|
| 最好：插入表尾 | `0` | `O(1)` |
| 最坏：插入表头 | `n` | `O(n)` |
| 平均 | `n / 2` | `O(n)` |

### 删除操作

删除第 `i` 个元素，并用引用参数返回被删除的值。

删除前需要判断 `i` 是否合法：

```text
1 <= i <= length
```

删除过程：

1. 保存被删除元素。
2. 从被删除位置的后一个元素开始，依次向前移动一位。
3. 表长减 `1`。

核心代码逻辑：

```cpp
e = L.data[i - 1];

for (int j = i; j < L.length; j++) {
    L.data[j - 1] = L.data[j];
}

L.length--;
```

**Python 示例：**

```python
e = L.data[i - 1]

for j in range(i, L.length):
    L.data[j - 1] = L.data[j]

L.length -= 1
```

注意：

- 删除时从前向后移动。
- 插入时从后向前移动。
- 被删除元素通过引用参数带出函数。

时间复杂度：

| 情况 | 移动次数 | 时间复杂度 |
|---|---:|---:|
| 最好：删除表尾 | `0` | `O(1)` |
| 最坏：删除表头 | `n - 1` | `O(n)` |
| 平均 | `(n - 1) / 2` | `O(n)` |

### 健壮性

在插入和删除中强调：

> 自己封装的基本操作不仅要逻辑正确，还要让调用者容易使用，并且能明确知道操作成功还是失败。

因此函数通常返回布尔值：

- 成功返回 `true`。
- 失败返回 `false`。

调用者根据返回值判断后续操作。

## 2.4 顺序表的查找

### 按位查找

按位查找是取得线性表中第 `i` 个元素。

在顺序表中：

```cpp
return L.data[i - 1];
```

**Python 示例：**

```python
def get_element(L, i):
    return L.data[i - 1]
```

因为位序从 `1` 开始，数组下标从 `0` 开始，所以需要减 `1`。

时间复杂度：

```text
O(1)
```

这表明顺序表支持随机访问。

### 按值查找

按值查找是在线性表中寻找值等于 `e` 的元素，并返回其位序。

核心逻辑：

```cpp
for (int i = 0; i < L.length; i++) {
    if (L.data[i] == e) {
        return i + 1;
    }
}
```

**Python 示例：**

```python
def locate_element(L, e):
    for i in range(L.length):
        if L.data[i] == e:
            return i + 1
    return 0
```

时间复杂度：

| 情况 | 比较次数 | 时间复杂度 |
|---|---:|---:|
| 最好：第一个元素命中 | `1` | `O(1)` |
| 最坏：最后一个元素命中或查找失败 | `n` | `O(n)` |
| 平均 | `(n + 1) / 2` | `O(n)` |

### 结构类型能否直接比较

基本类型可以直接使用 `==` 比较。

例如：

```cpp
int a = 1;
int b = 1;

if (a == b) {
    // ...
}
```

**Python 示例：**

```python
a = 1
b = 1

if a == b:
    print("equal")
```

但 C 语言中的结构类型通常不能直接使用 `==` 比较，需要逐项比较结构体中的分量。

- 考试科目如果是“数据结构”，通常更重视数据结构和算法思想。
- 考试科目如果是“C 语言程序设计”，则更要注意 C 语言语法是否严格。
- 答题时应以目标院校历年真题要求为准。

### 位序与数组下标
- 位序从 `1` 开始。
- 数组下标从 `0` 开始。

题目中如果说“删除第 `i` 个元素”，通常指位序。

如果题目说“删除下标为 `i` 的元素”，则是从 `0` 开始。

做题时必须分清两种表述。

## 2.5 单链表

链表是用链式存储实现的线性表，包括单链表、双链表、循环链表和静态链表。

### 单链表的定义

单链表中的每个结点包含：

- 数据域 `data`：保存数据元素。
- 指针域 `next`：保存后继结点的地址。

每个结点只包含一个指向后继的指针，因此叫单链表。

### 单链表的优点和缺点

与顺序表相比：

- 结点可以离散存放，不要求大片连续空间。
- 扩展容量方便，只需申请新的结点空间。
- 不支持随机存取。
- 找第 `i` 个结点时，只能从表头逐个向后寻找。

### 结点和链表类型定义

课本常见写法：

```cpp
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```

**Python 示例：**

```python
from dataclasses import dataclass

@dataclass
class LNode:
    data: object = None
    next: "LNode | None" = None
```

含义：

- `LNode` 强调这是一个结点。
- `LinkList` 强调这是一个指向结点的指针，用来表示单链表。

两种类型本质等价，但代码中会通过名称强调不同含义。

### 带头结点和不带头结点

#### 不带头结点

- 头指针直接指向第一个数据结点。
- 空表判断：`L == NULL`。
- 对第一个结点的插入和删除需要特殊处理。

#### 带头结点

- 头指针指向头结点。
- 头结点不保存实际数据。
- 第一个数据结点是 `L->next`。
- 空表判断：`L->next == NULL`。

指出：

> 带头结点的代码通常更方便，因此后续代码默认使用带头结点。考试中两种方式都可能出现，必须看清题意。

### 初始化

不带头结点：

```cpp
bool InitList(LinkList &L) {
    L = NULL;
    return true;
}
```

**Python 示例：**

```python
def init_list():
    return None
```

带头结点：

```cpp
bool InitList(LinkList &L) {
    L = (LNode *)malloc(sizeof(LNode));
    if (L == NULL) {
        return false;
    }
    L->next = NULL;
    return true;
}
```

**Python 示例：**

```python
def init_list():
    return LNode()
```

不带头结点时，头指针必须指向 `NULL`，防止保存脏数据。

## 2.6 单链表的插入和删除

### 按位插入

在第 `i` 个位置插入元素 `e`。

主要步骤：

1. 找到第 `i - 1` 个结点。
2. 申请一个新结点。
3. 把新结点的 `next` 指向第 `i` 个结点。
4. 把第 `i - 1` 个结点的 `next` 指向新结点。

带头结点时，头结点可以看作第 `0` 个结点，因此插入第 `1` 个位置也不需要单独处理。

不带头结点时，插入第 `1` 个位置需要修改头指针，因此要单独处理。

核心指针操作：

```cpp
s->next = p->next;
p->next = s;
```

**Python 示例：**

```python
s.next = p.next
p.next = s
```

顺序不能颠倒。

如果先执行：

```cpp
p->next = s;
s->next = p->next;
```

**Python 示例：**

```python
# 错误示例：先修改 p.next 会丢失原来的后继结点
p.next = s
s.next = p.next
```

新结点的 `next` 可能指向自己，链表会被破坏。

时间复杂度：

- 插入表头：找到前驱很快，`O(1)`。
- 插入其他位置：需要寻找第 `i - 1` 个结点。
- 平均和最坏：`O(n)`。

### 后插操作

给定结点 `p`，在 `p` 之后插入元素 `e`。

步骤：

1. 申请新结点 `s`。
2. `s->data = e`。
3. `s->next = p->next`。
4. `p->next = s`。

时间复杂度：

```text
O(1)
```

### 前插操作

给定结点 `p`，在 `p` 之前插入元素 `e`。

如果只给 `p`，无法直接找到前驱。

两种方案：

1. 传入头指针，从头查找 `p` 的前驱，时间复杂度 `O(n)`。
2. 在 `p` 后插入新结点，再交换两个结点的数据，时间复杂度 `O(1)`。

第二种方法不改变结点的逻辑关系，只交换数据。

### 按位删除

删除第 `i` 个结点。

带头结点时：

1. 找到第 `i - 1` 个结点 `p`。
2. 令 `q = p->next`。
3. 保存 `q->data`。
4. 令 `p->next = q->next`。
5. 释放 `q`。

被删除的数据通过引用参数带回调用者。

时间复杂度：

- 删除第一个数据结点：`O(1)`。
- 最坏和平均：`O(n)`。

### 删除给定结点

如果只给定结点 `p`，通常无法直接找到其前驱。

可以把后继结点的数据复制到 `p`，再删除后继结点。

时间复杂度：

```text
O(1)
```

但这种方法有局限：

> 如果 `p` 正好是最后一个结点，就无法通过后继结点间接删除。

此时只能从表头查找 `p` 的前驱。

指出：

> 这是单链表只能单向查找带来的限制，也引出了双链表。

## 2.7 单链表的查找和建表

### 按位查找

从头结点开始逐个向后扫描，让指针移动 `i` 次。

平均和最坏时间复杂度：

```text
O(n)
```

如果 `i` 非法，返回 `NULL`，调用者据此判断失败。

### 按值查找

从第一个数据结点开始逐个比较。

找到则返回结点指针，找不到则返回 `NULL`。

时间复杂度：

```text
O(n)
```

### 求表长

从第一个数据结点开始遍历，每访问一个结点计数器加一。

时间复杂度：

```text
O(n)
```

### 尾插法建立单链表

基本思路：

- 每次把新结点插到表尾。
- 维护一个尾指针 `r`，始终指向当前尾结点。

核心指针操作：

```cpp
r->next = s;
r = s;
```

**Python 示例：**

```python
r.next = s
r = s
```

时间复杂度：

```text
O(n)
```

如果每次都从表头查找表尾，时间复杂度会退化为 `O(n^2)`。

### 头插法建立单链表

每次把新结点插入头结点之后。

核心指针操作：

```cpp
s->next = L->next;
L->next = s;
```

**Python 示例：**

```python
s.next = head.next
head.next = s
```

特点：

> 输入顺序和最终链表顺序相反。

头插法的重要应用：

- 链表逆置。
- 将原链表中的结点依次取下，再重新插入头结点之后。

强调：

> 头插法实现链表逆置是重要考点。

## 2.8 双链表

双链表在单链表基础上增加一个前驱指针。

```cpp
typedef struct DNode {
    ElemType data;
    struct DNode *prior;
    struct DNode *next;
} DNode, *DLinkList;
```

**Python 示例：**

```python
from dataclasses import dataclass

@dataclass
class DNode:
    data: object = None
    prior: "DNode | None" = None
    next: "DNode | None" = None
```

### 初始化

带头结点的空双链表：

```cpp
L->prior = NULL;
L->next = NULL;
```

**Python 示例：**

```python
L.prior = None
L.next = None
```

### 后插操作

在结点 `p` 后插入结点 `s`：

```cpp
s->next = p->next;

if (p->next != NULL) {
    p->next->prior = s;
}

s->prior = p;
p->next = s;
```

**Python 示例：**

```python
s.next = p.next

if p.next is not None:
    p.next.prior = s

s.prior = p
p.next = s
```

如果 `p` 是最后一个结点，不判断 `p->next` 会出现空指针错误。

指针修改顺序不能随意颠倒。

### 删除操作

删除结点 `p` 的后继 `q`：

```cpp
p->next = q->next;

if (q->next != NULL) {
    q->next->prior = p;
}

free(q);
```

**Python 示例：**

```python
p.next = q.next

if q.next is not None:
    q.next.prior = p
```

同样要考虑 `q` 是最后一个结点的情况。

### 查找

双链表虽然能向前和向后遍历，但仍不支持随机存取。

按位查找和按值查找都需要遍历：

```text
O(n)
```

## 2.9 循环链表

### 循环单链表

普通单链表的尾结点 `next` 指向 `NULL`。

循环单链表的尾结点 `next` 指向头结点。

空表判断：

```cpp
L->next == L
```

**Python 示例：**

```python
L.next is L
```

从任意结点出发，都可以遍历整个循环单链表。

如果让链表指针指向尾结点：

- 找头结点：`rear->next`，`O(1)`。
- 找尾结点：`rear`，`O(1)`。

因此经常操作表头或表尾时，可以让指针指向尾结点。

### 循环双链表

循环双链表中：

- 尾结点的 `next` 指向头结点。
- 头结点的 `prior` 指向尾结点。

空表时：

```cpp
L->next == L;
L->prior == L;
```

**Python 示例：**

```python
L.next is L and L.prior is L
```

优点：

> 插入和删除最后一个结点时，不需要像普通双链表那样额外判断后继是否为空，因为尾结点的 `next` 始终指向头结点。

### 写链表代码的通用检查点

总结了所有链表代码都应关注的边界：

1. 空表如何表示。
2. 如何初始化空表。
3. 如何判断表头结点。
4. 如何判断表尾结点。
5. 插入表头、表中、表尾时是否需要分别处理。
6. 删除表头、表中、表尾时是否需要分别处理。

## 2.10 静态链表

静态链表用数组模拟链表。

结点包含：

- `data`：数据元素。
- `next`：下一个结点的数组下标，也叫游标。

常见约定：

- 下标 `0` 的结点作为头结点。
- `next == -1` 表示空指针，即没有后继。
- `next == -2` 可以标记空闲结点。

### 特点

- 存储空间连续，但逻辑相邻结点在数组中不一定相邻。
- 结点关系由游标表示。
- 插入和删除只需修改游标，不需要像顺序表一样移动大量元素。
- 不支持随机存取。
- 容量固定。

静态链表适合不支持指针的语言，或元素数量基本固定的场景。

老师提到：

> 操作系统中的文件分配表 FAT，本质上可以理解为一种静态链表。

## 2.11 顺序表和链表的比较

### 逻辑结构

顺序表和链表都属于线性表，逻辑结构都是线性结构。

### 存储结构

顺序表：

- 随机存取。
- 存储密度高。
- 要求大片连续空间。
- 容量扩展不方便。

链表：

- 不支持随机存取。
- 需要额外存储指针。
- 结点可以离散存放。
- 容量扩展方便。

### 创建和销毁

顺序表：

- 初始化时需要预分配连续空间。
- 空间过大浪费，空间过小容易满。
- 动态分配扩容需要复制数据。

链表：

- 初始化时通常只需一个头结点。
- 扩容时申请一个新结点即可。
- 销毁时需要逐个释放结点。

静态数组空间由系统在生命周期结束时回收。

`malloc` 申请的堆区空间必须手动 `free`。

### 插入和删除

两种结构的平均和最坏时间复杂度通常都是：

```text
O(n)
```

但原因不同：

- 顺序表主要耗时间在移动大量元素。
- 链表主要耗时间在从表头查找目标位置。

如果数据元素很大，移动元素的实际成本可能很高。

如果已经找到链表中的目标结点，修改指针本身只需要 `O(1)`。

### 查找

顺序表：

- 按位查找：`O(1)`。
- 无序按值查找：`O(n)`。
- 有序表可以折半查找：`O(log n)`。

链表：

- 按位查找：`O(n)`。
- 按值查找：`O(n)`。
- 即使有序，也不能高效折半查找。

### 选择建议

优先使用链表：

- 表长难以估计。
- 频繁插入和删除。
- 不要求频繁按位访问。

例如，餐厅排队取号和叫号系统。

优先使用顺序表：

- 表长可以预估且稳定。
- 查询操作较多。
- 需要频繁按位访问。

例如，班级学生点名系统。

总结了一种回答开放题的框架：

> 先分析逻辑结构，再分析存储结构，最后分析主要基本操作，得出选择结论。

## 2.12 小结

- 线性表是具有相同数据类型的有限序列。
- 位序从 `1` 开始，数组下标从 `0` 开始。
- 顺序表用连续空间实现线性表。
- 顺序表支持 `O(1)` 随机访问。
- 顺序表插入和删除通常需要移动元素。
- 插入平均移动约 `n / 2` 个元素。
- 删除平均移动约 `(n - 1) / 2` 个元素。
- 插入时从后向前移动，删除时从前向后移动。
- 基本操作要有健壮性，并给调用者明确反馈。
- 参数修改结果需要带回时，应使用引用参数。
